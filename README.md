# Fake Loading Bar for Lazy AI Agents

This pitch sells a progress screen that looks busy while the agent behind it does nothing at all. The human pays a dollar an hour to watch a convincing bar crawl forward, stays polite, and never notices the work never starts.

## Run

```sh
python3 main.py
```

This writes the pitch to `/output/entry.txt`. Python standard library only, no third party packages.
